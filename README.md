# AI Agent 課程顧問 Bot

「AI Agent 學分學程」課程的貫穿全期實作專案。在 Coze 平台上，逐步組裝一個能依照使用者背景與需求，推薦「該從哪個單元切入」的課程顧問機器人。

## 專案動機

選擇這個題目，不只是配合作業要求，也是為了解決自己真實的需求——目前規劃在 4-5 週內壓縮完成原本 10 週份的單元進度，需要一個工具幫忙判斷每個階段該優先學什麼、該注意哪些銜接。

## 核心情境（Target / Input / Output）

- **Target**：想加入或正在修習 AI Agent 學分學程的學習者，不確定該從哪個單元/主題切入
- **Input**：使用者背景（例如科系、先備技能）+ 想達成的目標（例如「想學會做一個能查資料的機器人」）
- **Output**：根據課綱推薦適合的起始單元與學習順序，並簡述該單元會學到什麼

## 技術架構與功能對應

隨課程進度逐週疊加，每完成一個單元就更新對應列的狀態。

| Coze 功能 | 對應 Agent 元素 | 對應課程單元 | 狀態 |
|---|---|---|---|
| Model 選擇 | LLM / 大腦 | 單元 1 | 待建立 |
| Persona / Prompt | 目標與語氣設定 | 單元 0-2 | 待建立 |
| Variable | 記住使用者背景（性別/職業/年齡） | 單元 3 | 待建立 |
| Knowledge | 課綱作為知識庫 | 單元 4 | 待建立 |
| Plugin | 查詢單元參考網址 | 單元 5 | 待建立 |
| Workflow / Intent | 判斷「想上什麼課」意圖，觸發推薦 | 單元 6-7 | 待建立 |
| Guardrail | 防止不當內容 | 單元 8 | 待建立 |
| 部署 | LINE / 網頁 / Skill（依老師建議彈性選擇） | 單元 9 | 待建立 |
